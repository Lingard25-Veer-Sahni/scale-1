## Name match overruled

The check matches on company names, so a short generic brand will collide
eventually. One did:

- **Leap** matched NSE's *LEAP India Limited* (LEAPIND, listed 14-Aug-2026).
  That is a pallet and logistics-equipment leasing company, not the Bengaluru
  study-abroad edtech. Leap stays tracked; the override is recorded in
  `NOT_THE_SAME_COMPANY` in the build script with this reason.

Every other match was checked by hand against the exchange record and is a
genuine listing — including Moneyview and Physicswallah, which only match once
spacing is normalised.

## What is not checked

- **Foreign listings.** The NASDAQ rows above were excluded by hand. Nothing
  catches the next one automatically.
- **NSE SME.** The SME master file is served nearly empty (one row), so SME
  listings are effectively unchecked.
- **BSE-only suspended scrips.** The bhavcopy only carries scrips that traded
  that day.
- **Valuation freshness.** Figures are as of the source pages' dates above.
